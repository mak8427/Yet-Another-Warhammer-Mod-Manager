## Evidence policy

Path evidence must exist in this tree and, when a test name is given, that name must occur in the file. PR evidence must carry a GitHub URL, a head SHA, and QA state; done PR evidence must be QA-approved at that head or merged. A PR path is accepted for an open PR because this is a capability score, not a release-readiness score. QA audits PR evidence; the script can only validate its shape.

node scripts/parity-report.mjs          # print the report and verify this file
node scripts/parity-report.mjs --write  # regenerate this file from PARITY.yaml
